## ISOCodex — .NET libraries

Domain models and reference data for postal addresses, countries and money, published on NuGet.

| Library | What it provides | Documentation | NuGet |
| --- | --- | --- | --- |
| **ISOCodex.Addressing** | A flexible postal address domain model with configurable validators, formatters and address-entry metadata. | [Docs & examples](https://github.com/AnthonyPWatts/ISOCodex.Addressing.Docs) | [![ISOCodex.Addressing NuGet version](https://img.shields.io/nuget/v/ISOCodex.Addressing?logo=nuget&label=NuGet)](https://www.nuget.org/packages/ISOCodex.Addressing) |
| **ISOCodex.Countries** | Strongly typed country codes, territory and subdivision data, explicit lookups and display names. | [Docs & examples](https://github.com/AnthonyPWatts/ISOCodex.Countries.Docs) | [![ISOCodex.Countries NuGet version](https://img.shields.io/nuget/v/ISOCodex.Countries?logo=nuget&label=NuGet)](https://www.nuget.org/packages/ISOCodex.Countries) |
| **ISOCodex.Currency** | Immutable money values, currency-aware arithmetic, explicit rounding and allocation. | [Docs & examples](https://github.com/AnthonyPWatts/ISOCodex.Currency.Docs) | [![ISOCodex.Currency NuGet version](https://img.shields.io/nuget/v/ISOCodex.Currency?logo=nuget&label=NuGet)](https://www.nuget.org/packages/ISOCodex.Currency) |

These repositories contain public documentation, runnable examples and support. Library implementation and development history are maintained privately.

The core libraries support .NET Framework 4.7.2+ and modern .NET through .NET Standard 2.0. Integration packages have their own targets; see [framework compatibility](https://github.com/AnthonyPWatts/ISOCodex.Addressing.Docs/blob/main/docs/compatibility.md).
